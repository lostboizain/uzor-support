Uzor 隐私政策

适用于 Uzor 1.0 · 更新日期：2026-10-24

本政策说明 Uzor 免费版本的数据处理方式，不包含尚未提供的 Uzor 官方 AI、官方服务账号或付费 Pro。

1. 我们是谁

Uzor 是用于私人笔记、日志、阅读、闪卡复习和写作的应用，提供 iPhone、iPad、Mac 版本及 Apple Watch 录音伴侣。

你无需创建 Uzor 账号即可使用本地功能。当前版本免费提供应用功能及 iCloud 同步，RSS 订阅上限为 200 个；不销售 Pro、不提供官方 AI 调用额度。你自行连接的 AI 服务商可能另行收费。

2. 保存在设备上的资料

你创建或导入的笔记、日志、文字、图片、视频、录音、阅读文件、RSS 订阅及文章、摘录、卡片、复习记录、文稿和设置首先保存在设备上。处理这些资料是为了保存、查找、组织、阅读、播放和复习。应用会保存内容标识、创建和修改时间等必要元数据，并在本机保存恢复快照和少量运行诊断信息。

Uzor 没有将整个资料库上传至开发者服务器的功能。若你启用 iCloud、调用自带 API、读取在线内容或主动向支持邮箱发送资料，则会发生下文说明的传输。“本地优先”不代表所有可选功能都不联网。

本版本没有广告 SDK、广告标识符读取或开发者自建的行为分析上传功能。我们不通过本应用出售资料或进行跨应用广告跟踪。

3. iCloud 同步

当你连接并使用 iCloud 同步时，工作区内容、相关设置、修改记录及原始附件通过 Apple CloudKit 传送到你 Apple 账户对应的私有数据库，再同步至你连接的其他设备。它不通过开发者的云服务器中转。应用在设备上保存与该 iCloud 资料库对应的账号范围标识和同步基线，用于避免混用不同账户的资料及处理冲突。

Apple 按其 iCloud 服务安排处理云端数据。请参阅 Apple 隐私政策。Uzor 的同步免费，但仍受你的 iCloud 可用空间、网络及系统运行条件影响。

关闭同步只停止相应同步操作，并不等于删除云端已有副本；卸载某台设备上的应用也不会自动删除其他设备、iCloud 或你另行导出的备份。冲突恢复副本与删除标记可能继续保留，以避免误删和恢复数据。需要整理云端数据时，请先备份并检查系统 iCloud 存储管理选项，或联系支持。

4. 录音、转文字与 Apple Watch

仅在你主动开始录音并授权麦克风后，Uzor 才录制声音。手机和 Mac 录音保存在本机资料库。Apple Watch 录音先保存在手表，在系统允许传输时通过 WatchConnectivity 发送给配对的 iPhone；手机确认已保存后，手表会尝试清理已送达的音频副本，同时保留传输状态记录。未送达或异常中断的录音可能保留用于恢复。

收到的手表录音会进入对应日期的日志；iPhone 打开并满足同步条件后可继续通过 iCloud 同步。传输和同步受设备连接、系统调度及应用状态影响，不能保证录完后立即出现在所有设备。

你主动点“转文字”后，应用请求系统语音识别权限，并只在设备及所选语言支持本机识别时转写。当前实现强制使用本机识别；不支持时保留原始录音并提示，不会自动改走云端转写。原始录音如被纳入 iCloud 同步或导出备份，仍会按相应路径传输。

5. 图片识字与自带 API 的 AI 功能

“图片/截图制卡”先使用 Apple Vision 在设备上识别图片文字。识别本身不会将图片发给 AI 服务商。你可以检查、修改识别结果，再决定是否生成卡片。

AI 制卡和资料归纳是可选功能。使用前，你需要在“设置 → AI”填写自己的 HTTPS 接口地址、模型名称和 API 密钥。保存配置不会调用模型。接口、模型和密钥保存在当前设备的系统钥匙串，不进入笔记资料库、Uzor 导出备份或 iCloud 同步，其他设备需分别配置。

生成前，界面展示服务商地址、模型、本次资料及发送确认。你确认后，应用直接向所选接口发送：本次选中或输入的文字、资料标题、引用所需的内部来源和证据标识、摘要范围标记、语言及任务要求，并在鉴权请求头中发送 API 密钥。它不会自动发送整个资料库、未选资料、截图原文件或原始录音。所选文字本身包含的个人信息或网址也会一起发送。

收到的模型输出先作为草稿供你检查，保存后进入本机资料库，并可按你的同步选择进入 iCloud。你可以不使用 AI、取消后续请求或在设置中移除连接。取消本地等待不能撤回服务商已经收到的请求，也不能保证服务商不计费。

当前预设包括 DeepSeek、MiniMax 中国大陆、MiniMax 国际及自定义兼容接口。服务商会接收到请求和网络连接信息，可能将其与供应商账户关联；具体存储地区、保存期、训练或服务改进用途取决于所选服务及账号条款。Uzor 不承诺所有服务商“零留存”或“不会训练”。

  • DeepSeek：隐私政策与开放平台服务协议。其政策说明境内运营的个人信息存储于中国境内，按服务目的所需期限及适用例外保存；通用政策包含训练、优化等用途。具体 API 的适用范围、退出及留存安排应以你的账号条款为准，不能把通用产品的退出设置直接视为对全部 API 生效。
  • MiniMax 中国大陆：隐私政策与用户协议。API 提交内容、密钥和账户鉴权信息用于计算与问题处理；条款另列算法改善，以及加密、去标识化后无法识别个人的服务优化、统计和安全用途。境内运营的个人信息按其政策在中国境内存储，保留必要期限，备份清除可能延后。
  • MiniMax 国际：隐私政策与服务条款。其条款允许为提供、维护、改进服务和安全处理输入输出；政策说明相关个人数据存储于美国数据中心，可能由其关联方或服务商跨地区处理，按目的和适用法律决定保存期限。
  • 自定义接口：接收方、地区和数据规则由你填写的地址及相应服务条款决定。使用前请查看该服务的隐私与 API 说明。

服务商还会处理调用时间、模型、请求次数及令牌用量，用于计量、服务运行及使用统计；IP 地址、请求标识和错误状态等技术日志可用于安全和排障。DeepSeek 的政策另说明会从 IP 推断大致地区用于安全检查。这不代表 Uzor 读取 GPS 或向服务商发送设备广告标识符。

以上预设的公开文件没有为 Uzor 提供统一的 API 固定删除天数。服务商可能保留鉴权、请求及安全日志；具体账号安排或另行约定可能不同。你可以不使用外部 AI，或在发送前删去无需处理的私人信息。

6. RSS、网页导入及链接预览

当你获取网页正文、添加或刷新 RSS / Atom、生成链接预览时，设备直接请求对应网站。对方及其网络服务商可接收到访问 URL、IP 地址、请求时间和应用网络标识等信息。订阅地址若含个人令牌，该地址本身也会传给对应站点。

原生正文与元数据抓取不带网站登录 Cookie，导入的网页转换为本地文字，不执行网页脚本。链接卡片显示的远程图片可另行访问图片所在站点；该请求与正文抓取是不同路径。外部链接交给系统浏览器或相应应用打开，其处理规则由该服务决定。

来源网站可能保存访问日志。我们不能替任意网站承诺删除期限或用途。你可以不导入在线链接、删除订阅以停止之后对该订阅的刷新，并使用本地导入资料。已保存的文章不会因为退订而自动从所有备份中清除。

7. 权限与用户选择

系统功能何时使用不授权的影响
麦克风你开始录音时不能录音，已有文字和录音不因此被删除
语音识别你请求录音转文字时不能转写，原始音频保留
文件/照片选择你选择要导入的资料时不导入未选文件，其他本地功能可继续使用
iCloud你连接并使用同步时本机功能仍可用，无法完成相应云同步

你可以通过系统设置调整麦克风和语音识别权限。撤回权限或停止使用某项功能不会撤回已经送出的资料；已传给 Apple、AI 接口或网站的数据需按相应服务的数据管理方式处理。

8. 支持邮件、诊断与官网

如果你主动发邮件，我们会收到你的邮件地址、正文及主动附上的截图、设备情况、日志和其他附件，用于答复和排查。支持邮件存储在 Gmail 邮箱；Google 使用全球基础设施，邮件可能在你所在国家或地区以外处理，详见 Google 隐私政策。请不要发送密码、API 密钥或与问题无关的私人笔记；可以先遮盖无关内容。

应用会在本机保存最近一次界面启动诊断，内容可能包括系统错误、资源 URL 和布局信息；当前没有自动上传至开发者服务器的通道。若你通过 Apple 的反馈/诊断功能或邮件主动提供资料，我们收到的副本会用于相关问题处理。

我们仅为答复、排障及处理相应请求使用收到的支持资料。问题处理完成后，常规支持记录最长保留 12 个月，无关或不再需要的附件尽早删除。收到经核实的删除请求后，我们会清理所持邮箱记录及为该问题另存的工作副本；如依法必须保留或为处理尚未结束的争议所必要，将说明范围和理由。邮箱服务的备份清除仍受其规则约束。

本支持与隐私网站由 GitHub Pages 托管。我们提供的是静态文档，无登录、表单、广告、行为分析脚本或浏览器偏好存储，不接收笔记库或 API 密钥。GitHub 会记录并保存访客 IP 地址用于安全，并按其隐私声明处理网络请求和服务使用信息。

相关数据可能在美国及其他国家或地区处理，保存期限依处理目的及适用法律决定；GitHub 没有在所引用文件中承诺 Pages 访问日志的统一删除天数。请参阅 GitHub Pages 数据收集说明与 GitHub 隐私声明。这项网站托管与应用资料库的本机存储、iCloud 同步分别运行。

9. 保存、删除及你的权利

你可以在应用内编辑、导出和删除资料，并自行管理导出文件。应用保留本机恢复快照以降低意外丢失风险：普通 JSON 恢复快照按数量轮换，当前保留上限为 30 份，损坏恢复文件另行保留；这不是“30 天后自动删除”的承诺。删除页面或附件不等于即时清除所有恢复快照、媒体文件、其他设备及云端副本。

移除 AI 连接会删除本机保存的这份配置和密钥，不会删除服务商已有记录。你可以向上述邮箱请求了解、更正或删除我们实际持有的支持信息。我们会核实请求与资料的关系，避免把资料交给无权访问的人；第三方保存的资料需向其提出请求。当前没有 Uzor 官方服务账号，因此没有此类账号的注销步骤。

我们会在收到个人信息请求后 15 个工作日内回复；需要补充核实或无法立即完成时，会说明原因和后续安排。这是请求回复期限，不代表所有第三方备份都能在同一期限内删除。

10. 安全、未成年人和政策变化

我们采用系统钥匙串、应用沙盒、必要权限及 AI HTTPS 请求等措施减少未经授权访问。RSS 或网页来源可能使用 HTTP；网络和设备本身也会影响安全，不能承诺绝对安全。请妥善保管设备及备份，只向你信任的接口发送有权处理的资料。

Uzor 并非专门面向儿童设计，当前没有家长控制或年龄核验机制。未成年人使用外部 AI 和网站时应遵守相关服务的年龄规定并获得适当监护指导。若你认为我们收到不适当提供的未成年人个人信息，请联系邮箱核查；我们不会把商店年龄分级等同于监护同意。

功能、接收方或处理方式发生实质变化时，我们会更新本政策，并在需要时另行告知和取得同意。延期的官方 AI 或收费服务若以后上线，将另行说明；本政策不预先授权尚未提供的服务。
